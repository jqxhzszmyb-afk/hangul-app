# 👧🏻 한글 파닉스 교육용 웹앱 (Hangul App)

아이들이 태블릿 브라우저에서 쉽고 재미있게 한글을 익힐 수 있도록 설계된 순수 PWA(Progressive Web App)입니다. 오프라인 모드를 완벽 지원하며, 부모님이 직접 단어장을 유연하게 관리할 수 있습니다.

## 🚀 주요 기능

### 1. 자모 조합 (초성+중성+종성)
* 화면에 있는 14자음과 10모음을 드래그 앤 드롭으로 조합 상자에 넣으면 실제 한글 음절이 생성됩니다.
* 아이패드에서의 원활한 드래그를 위해 터치 스크롤 방지 로직이 적용되어 있습니다.
* `듣기` 버튼을 누르면 기기의 내장 한국어 음성(TTS)으로 글자를 읽어줍니다.

### 2. 가나다 표 (파닉스 학습)
* '가'부터 '히'까지 140개의 기본 글자를 시각적으로 한눈에 들어오는 바둑판 배열로 제공합니다.
* 글자를 터치하면 주황색으로 반전되며 톡 튀어오르는 시각적 피드백과 함께 글자를 또렷하게 읽어줍니다.
* **파닉스 튜닝**: '져', '쳐', '죠' 등의 이중모음을 [지여], [치여]와 같이 분리된 파닉스 발음으로 몰래 치환하여, 아이가 시각적 철자와 청각적 소리를 명확히 구분할 수 있도록 튜닝되었습니다.

### 3. 단어 읽기 (구글 시트 연동 📊)
* 부모님이 코딩을 몰라도 **구글 스프레드시트 단어장**에 아이 친구 이름이나 관심사(이모지)를 입력하기만 하면 앱에 자동으로 동기화됩니다.
* 학습 시 단어 순서 암기를 방지하기 위해 앱 실행 시 단어가 **무작위(Random Shuffle)**로 섞여 나옵니다.
* `◀ 이전`, `다음 ▶` 버튼으로 단어장을 넘겨볼 수 있으며, 단어 전체를 누르면 통으로 읽어줍니다.

### 4. 직접 쓰기 (스케치북)
* 빈 캔버스에 자유롭게 손가락으로 글씨를 쓰거나 그림을 그릴 수 있는 조용한 스케치북 공간입니다.

## 🛠 실행 및 설치 방법 (아이패드 기준)
1. 아이패드의 **Safari 브라우저**에서 앱 주소(`https://jqxhzszmyb-afk.github.io/hangul-app`)로 접속합니다.
2. 주소창 옆의 공유 버튼(↑)을 누르고 **'홈 화면에 추가'**를 선택합니다.
3. 바탕화면에 생성된 귀여운 앱 아이콘을 누르면, 상단 주소창이 사라진 전체 화면 모드로 실행되며 인터넷이 끊긴 환경에서도 작동합니다!

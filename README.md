# 한글 웹앱 V1

태블릿 브라우저에서 바로 실행할 수 있는 순수 HTML/CSS/JavaScript 프로토타입입니다.

## 실행
1. `index.html`을 브라우저에서 엽니다.
2. `자모 + 만들기` 탭에서 자모를 터치/드래그합니다.
3. 조합 영역에 놓으면 음절이 생성됩니다.
4. `듣기`를 누르면 한국어 브라우저 음성으로 확인합니다.
5. `만들고 읽기` 탭에서 단어 경험을 확인합니다.

## 현재 V1
- 포스터형 14자음 + 10기본모음
- 자모 이름 음성
- 터치/마우스 드래그
- 초성+중성 조합
- 기본적인 종성 조합 로직
- `만들고 읽기` 샘플 단어
- 따뜻한 아이보리 UI
- 반응형 태블릿 레이아웃

## 다음 작업 후보

- 초성/중성 모양에 따른 실제 음절 배치
- 종성 포함 조합 UI 정교화
- 단어 콘텐츠와 학습 흐름 설계
- PWA 설치 지원
- 아이 음성 녹음/재생(기기 로컬 우선)

## 이번 수정
- 조합 박스 안에 아이가 놓은 자모 순서를 그대로 표시: `ㅋㅏㅁ`
- 아래 결과 영역에서 조합된 실제 음절을 표시: `캄`
- 한국어 음성 엔진을 우선 선택하도록 수정
- `ㅛ`는 브라우저 TTS의 고립 모음 오인식을 줄이기 위해 `요.`로 요청
- 단, `ㅛ` 같은 단일 자모의 정확한 발음은 기기/브라우저 TTS 엔진에 따라 달라질 수 있어 최종본은 녹음 음원을 사용하는 것이 가장 정확함

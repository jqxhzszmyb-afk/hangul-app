# 작업 완료 요약 (SUMMARY)

- **작업일**: 2026-09-25
- **작업명**: 단어 앞뒤 이동 및 구글 시트 기반 나만의 단어장(랜덤 셔플) 연동
- **작업 결과**: 기존 단어 읽기 탭의 버튼을 '이전', '다음'으로 분할하여 네비게이션 기능을 강화함. 또한 `fetch` API를 이용해 외부에 공개된 구글 스프레드시트(CSV)에서 단어 데이터를 동적으로 불러오도록 구현하였으며, 교육적 효과(순서 암기 방지)를 위해 불러온 배열을 Fisher-Yates shuffle 알고리즘으로 무작위 섞음. 서비스워커 버전 v7 갱신.
- **결정적 이유 (Rationale)**: 부모가 코드 수정 없이 비개발자 친화적인 도구(엑셀/시트)를 이용해 아이의 관심사나 친구 이름 등으로 학습 데이터를 유연하게 확장할 수 있도록 함.

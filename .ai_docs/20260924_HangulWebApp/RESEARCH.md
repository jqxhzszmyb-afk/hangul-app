# Phase 1: Research - 아이 주도형 한글 학습 웹앱 (ChatGPT V1 기반)

## 1. 개요
* **프로젝트명**: 아이 주도형 한글 학습 웹앱 (코드명: 한글 파닉스 앱 기획)
* **목표**: 아이가 스스로 한글의 원리를 경험하고 이해할 수 있는 인터랙티브 웹 애플리케이션 개발. ChatGPT와 작업했던 V1 프로토타입(HTML/CSS/JS)을 기반으로 고도화.

## 2. 기존 V1 프로토타입 분석
* **핵심 구조**: 
  - 순수 HTML, CSS, JavaScript (React 등 프레임워크 미사용)
  - 14자음 + 10기본모음 구성
  - 2개 탭: '자모 + 만들기', '만들고 읽기'
* **주요 기능**:
  - 자모 터치 시 자모 이름 음성 출력 (브라우저 TTS)
  - 자모 드래그 앤 드롭으로 조합 박스에 추가 (예: `ㅋ` `ㅏ` `ㅁ` 순차 표시)
  - 초성+중성+종성 조합 로직 구현 (하드코딩된 음절 맵 활용)
  - 따뜻한 아이보리 계열 UI, 태블릿 터치 대응
* **발견된 문제점/과제 (ChatGPT 분석 기록)**:
  - 브라우저 TTS 한계 (예: 'ㅛ'가 '여'로 들리는 현상 등) -> 궁극적으로 녹음된 음성 파일(mp3/wav)로 대체 필요.
  - 제공된 한글 조형 디자인 미반영 상태 (기본 폰트 사용).
  - PWA 미적용 상태.

## 3. 고도화 요구사항 (기획 방안)
* **단계적 마이그레이션 및 확장**:
  1. 현재의 순수 HTML/JS 구조를 React (또는 모던 번들러 기반)으로 전환할지, 기존 구조를 유지하며 살을 붙일지 결정. (일단 기존 구조를 최대한 재사용하여 빠르고 안정적으로 기능을 추가하는 방향으로 제안)
  2. 아이가 직접 그리는 **'인터랙티브 쓰기(Canvas)'** 기능 추가.
  3. TTS를 안정화하거나 로컬 음성 에셋 파일 시스템으로 교체할 수 있는 구조 마련.
  4. PWA(Progressive Web App) 기능 추가로 홈 화면에 앱처럼 설치.

## 4. 보안 및 규정 검토
* 순수 클라이언트 기반으로 데이터 수집이 없어 아동 개인정보 보호 규정(COPPA 등)에 부합.

# 한글 파닉스 앱 고도화 기획안 (Phase 2)

현재 앱은 훌륭한 교육적 뼈대(자모 조합, 단어 인지, 직접 쓰기)를 갖추고 있습니다. 아이들의 흥미를 더 오래 유지하고 학습 효과를 극대화하기 위해 다음과 같은 방향으로 앱을 발전시킬 수 있습니다.

## 1. 🎮 게이미피케이션 (놀이 요소 추가)
아이들은 일방적인 학습보다 상호작용(미션)이 있을 때 더 몰입합니다.
*   **"글자를 찾아라!" 퀴즈 모드**: "피카츄 글자를 만들어봐!"라는 음성이 나오고, 아이가 자음과 모음을 드래그해서 정답을 맞히면 화면에 화려한 폭죽(Confetti)이 터지며 칭찬 효과음이 나오는 기능.
*   **스탬프 / 칭찬 스티커 북**: 단어를 읽거나 글자를 하나 쓸 때마다 가상의 '참 잘했어요' 스탬프를 모을 수 있는 보상 시스템.

## 2. ✍️ 스마트 '직접 쓰기' (가이드 모드)
현재의 백지 도화지를 넘어, 실제 쓰기 연습을 돕는 기능입니다.
*   **따라 쓰기 밑그림 (점선 글씨)**: 오늘 배운 단어(예: 차탄)가 캔버스 배경에 연한 점선으로 깔려 있어, 아이가 그 위를 따라 쓸 수 있게 하는 기능.
*   **획순 애니메이션**: 글자를 어떻게 써야 하는지 별이나 캐릭터가 획순을 따라 움직이며 가이드해 주는 기능.

## 3. 👨‍👩‍👧‍👦 커스텀 단어장 (학부모 모드)
아이마다 좋아하는 관심사가 다릅니다. 부모님이 직접 단어를 추가할 수 있다면 활용도가 폭발적으로 늘어납니다.
*   **내 사진으로 단어 만들기**: 부모님이 가족사진이나 아이의 애착 인형 사진을 찍어서 앱에 올리고, "엄마", "아빠", "토끼" 등의 단어를 직접 추가할 수 있는 기능 (데이터는 기기에 안전하게 저장됨).
*   **주제별 단어장 분류**: 카봇, 포켓몬스터 외에도 '동물', '과일', '우리가족' 등 탭을 나누어 단어를 묶어 보여주는 기능.

## 4. 🗣️ 음성 품질 업그레이드 (선택 사항)
*   **초자연스러운 AI 목소리 적용**: 현재는 아이패드 내장 기계음(Siri 느낌)으로 소리가 나지만, Web Speech API의 한계를 넘어 구글이나 네이버의 고품질 AI 음성 엔진(유아 목소리, 애니메이션 성우 목소리 등)을 연동하여 훨씬 친근한 목소리로 읽어주게 업그레이드.

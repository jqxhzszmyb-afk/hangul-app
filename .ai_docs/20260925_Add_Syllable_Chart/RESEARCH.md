# Phase 1: Research - 기본 글자표(가~히) 탭 추가

## 목표
- 자모 조합 탭과 단어 읽기 탭 사이에 '글자표' (또는 '가나다') 탭을 추가.
- '가'부터 '히'까지 총 140자 (14개 자음 × 10개 모음)를 한눈에 볼 수 있는 표 형태로 제공.
- 각 글자를 터치하면 해당 글자의 소리(`speak`)를 들려줌.

## 관련 코드베이스 분석
1. **HTML (`index.html`)**
   - `<nav class="tabs">` 내에 새 버튼 추가 필요 (`<button class="tab" data-tab="chart">가나다 표</button>`).
   - 새 화면 컨테이너 `<section id="chart" class="screen">` 추가 필요.
2. **CSS (`style.css`)**
   - 140개의 글자가 모바일/태블릿 화면에 예쁘게 나오도록 Grid 레이아웃(`.chart-grid`) 추가 필요.
   - 열 10개(모음), 행 14개(자음) 구조로 스크롤 가능하게 구현.
3. **JS (`app.js` 및 `data.js`)**
   - `data.js`에 있는 `consonants` 배열(14개)과 `vowels` 배열(10개)을 이중 루프 돌려서 글자를 조합.
   - 이미 존재하는 `syllableMap` 객체를 활용하거나 로직으로 글자 코드를 결합하여 동적으로 버튼 생성.
   - 탭 전환 로직은 기존 코드가 `dataset.tab`을 통해 자동 처리하므로 별도 수정 불필요.

## 보안 및 비즈니스 로직 체크
